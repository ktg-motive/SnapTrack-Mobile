Version 1.4.0
Release Date: January 20, 2025

This major release introduces our new privacy-first authentication system with professional username-based email addresses, enhanced user profiles, and significant performance improvements.

New Features:

▸ Professional Username System: Create your personalized username@app.snaptrack.bot email address for receipt forwarding
▸ Privacy-First Authentication: New UUID-based authentication system supporting email-optional signup
▸ Enhanced User Profiles: Complete profile management with username and email display across all screens
▸ Cross-Platform Sync: Seamless authentication state synchronization between web and mobile platforms
▸ Universal Login: Single authentication endpoint supporting Google, Apple, email, and anonymous sign-in methods
▸ Apple Sign-In Enhancement: Full support for "Hide My Email" feature with automatic forwarding
▸ Smart Onboarding Flow: Integrated username selection during account creation
▸ Progressive Migration: Existing users receive upgrade prompts to claim their professional username

Enhancements:

▸ PDF Export Service: New microservice architecture eliminates memory crashes when exporting 50+ receipts
▸ Authentication Speed: Optimized UUID-based lookups reduce login time by 40%
▸ Profile Display Fix: Username and email now properly display in account menu and settings screens
▸ Username Management: Change your username directly in the app (once every 24 hours)
▸ Email Copy Function: Fixed crash when copying email address to clipboard
▸ Loading State Clarity: Separate loading indicators for each authentication method

Bug Fixes:

▸ Authentication Loading: Fixed spinner appearing on wrong button during sign-in
▸ Profile Data Loading: Resolved issue where username wasn't displaying despite being set
▸ Clipboard Crash: Fixed app crash when tapping copy email function
▸ Welcome Email Delivery: Corrected endpoint integration for automated welcome emails
▸ Memory Management: PDF export no longer causes application crashes with large datasets
▸ Session Persistence: Enhanced authentication state preservation across app restarts

Performance:

▸ Authentication Flow: 40% faster login times with optimized UUID lookups
▸ Profile Loading: Instant profile data display with improved caching
▸ Username Validation: Real-time availability checking with sub-second response
▸ Database Queries: Optimized indexes for 3x faster user data retrieval

This release represents a major milestone in SnapTrack's evolution, introducing a modern authentication architecture that prioritizes user privacy while maintaining backward compatibility. All existing users can continue using their current email addresses or upgrade to the new username-based system at their convenience.
