Version 1.6.0
Release Date: February 2, 2026

This release introduces biometric authentication to protect your financial data with Face ID and Touch ID support.

New Features:

▸ Face ID / Touch ID Lock: Secure your financial data with biometric authentication
▸ Privacy Protection: App content hidden in app switcher when biometrics enabled
▸ Auto-Lock: Automatic lock after 15 minutes of inactivity
▸ Biometric Setup Prompt: First-login prompt to enable biometric security
▸ Settings Toggle: Enable or disable Face ID Lock from Settings > Security

Enhancements:

▸ Secure Token Storage: Authentication tokens now stored in iOS Keychain with biometric protection
▸ Session Persistence: Navigation state preserved when unlocking app
▸ Activity Monitoring: Idle timeout resets on user interaction

Bug Fixes:

▸ React Hooks Order: Fixed hooks violation that could cause rendering errors
▸ Navigation Reset: App no longer resets to welcome screen after biometric unlock

Security:

▸ Biometric-Only Authentication: No passcode fallback option for stronger security
▸ Hardware-Backed Storage: Tokens protected by Secure Enclave on supported devices
▸ Force Re-Login: After 3 failed biometric attempts, requires full re-authentication
