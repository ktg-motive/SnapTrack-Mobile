# SnapTrack Version 1.4.0 Release Notes

## Version 1.4.0
**Release Date: January 20, 2025**

This major release introduces our new privacy-first authentication system with professional username-based email addresses, enhanced user profiles, and significant performance improvements across both web and mobile platforms.

## New Features

### Professional Username System
▸ **Username-Based Email Addresses**: Create your personalized username@app.snaptrack.bot email address for receipt forwarding
▸ **Privacy-First Authentication**: New UUID-based authentication system supporting email-optional signup
▸ **Enhanced User Profiles**: Complete profile management with username and email display across all screens
▸ **Cross-Platform Sync**: Seamless authentication state synchronization between web and mobile platforms

### Authentication Improvements
▸ **Universal Login**: Single authentication endpoint supporting Google, Apple, email, and anonymous sign-in methods
▸ **Apple Sign-In Enhancement**: Full support for "Hide My Email" feature with automatic forwarding
▸ **Smart Onboarding Flow**: Integrated username selection during account creation for professional email addresses
▸ **Progressive Migration**: Existing users receive upgrade prompts to claim their professional username

## Enhancements

### Performance & Reliability
▸ **PDF Export Service**: New microservice architecture eliminates memory crashes when exporting 50+ receipts
▸ **Authentication Speed**: Optimized UUID-based lookups reduce login time by 40%
▸ **API Consolidation**: Unified authentication reduces server requests and improves response times

### User Experience
▸ **Profile Display Fix**: Username and email now properly display in account menu and settings screens
▸ **Username Management**: Change your username directly in the app (once every 24 hours)
▸ **Email Copy Function**: Fixed crash when copying email address to clipboard
▸ **Loading State Clarity**: Separate loading indicators for each authentication method

### Developer Experience
▸ **Comprehensive Documentation**: Complete API reference for new authentication endpoints
▸ **Architecture Decision Records**: Added ADR-005 documenting username cooldown reduction
▸ **Migration Guides**: Step-by-step instructions for implementing UUID authentication
▸ **Platform Integration Guides**: Detailed implementation guides for web and mobile platforms

## Notes

This release represents a major milestone in SnapTrack's evolution, introducing a modern authentication architecture that prioritizes user privacy while maintaining backward compatibility. The new username system provides professional email addresses for all users while supporting those who prefer to keep their email private.

All existing users can continue using their current email addresses or upgrade to the new username-based system at their convenience. The dual-format email processing ensures zero service disruption during the transition period.

For technical details about the new authentication system, please refer to the updated API documentation.
